| 原稿 | 改编后的技术文档 |

原稿中100样本指标与安全性数字缺少可重复核验的原始记录，不作为本稿已验证性能。替换为11项仓库测试、六图两模型对比、功能消融及一次虚构输入的DeepSeek调用；均说明各自边界。原指标图不沿用，避免将历史陈述重新包装成新证据。
