# 已保存的验证证据

这里是从原交付版本保存的记录，不由日常测试覆盖。当前重新整理的验证输出写入根目录artifacts，并在仓库验收记录中汇总。旧记录里出现的旧路径和文档名属于当时布局，当前入口以根README为准。

| 文件 | 内容 | 边界 |
| --- | --- | --- |
| frontend-parity.json | 六个演示样例及无影像路径的API/原流程一致性 | 本地CNN和规则；远程模型禁用 |
| deepseek-validation.json | 一次虚构输入真实调用、七类回退 | 接口成功不等于临床质量验证 |
| demo-ablation.json | 六图两模型对比与关闭召回 | 精选样例；非独立性能评测 |
| model-metadata.json | 权重哈希、checkpoint轮次与配置 | 不能代替完整训练日志和作者证明 |
| external-model-metadata.json | 外部模型ID、版本与许可证声明 | 未验证远程模型运行或本地资源授权 |

这些文件证明已执行的具体检查，不证明全部参赛条件已满足。
